# GitHub Copilot para Engenharia de Software Moderna

Esta organização reúne os materiais, as demonstrações e os laboratórios do treinamento **GitHub Copilot para Engenharia de Software Moderna**.

## Preparação

- [Pre-work: preparando o ambiente do curso](https://github.com/impacta-ghcp-eng-moderna/00-pre-work) — valida o acesso ao GitHub, a criação de repositórios, o GitHub Codespaces e a execução da aplicação usada no treinamento.

## Módulo 01 — Do requisito à aplicação

Um walkthrough completo de desenvolvimento assistido pelo GitHub Copilot, seguido de um laboratório prático.

1. [Walkthrough: desenvolvimento assistido pelo Copilot](https://github.com/impacta-ghcp-eng-moderna/01-walkthrough-desenvolvimento-assistido) — construção ponta a ponta de uma aplicação .NET, do requisito à validação, com checkpoints e supervisão humana.
2. [Lab 01: inscritos em treinamentos](https://github.com/impacta-ghcp-eng-moderna/01-lab) — expansão da aplicação com o cadastro e a listagem de participantes inscritos.

**Apresentação:** [baixar slides do Módulo 01](./apresentacoes/01-ghcp-eng-moderna.pptx?raw=1)

## Módulo 02 — Da personalização ao controle

Uma sequência de demonstrações sobre os mecanismos de personalização e controle do GitHub Copilot, concluída por um laboratório de revisão delegada.

1. [Instruction files](https://github.com/impacta-ghcp-eng-moderna/02-demo-instructions) — aplicação de instruções em diferentes escopos para oferecer somente o contexto necessário.
2. [Prompt files](https://github.com/impacta-ghcp-eng-moderna/02-demo-prompt-file) — transformação de uma tarefa recorrente em um prompt reutilizável no VS Code.
3. [Custom agents, subagents e handoffs](https://github.com/impacta-ghcp-eng-moderna/02-demo-custom-agents) — especialização, delegação e transferência supervisionada de tarefas.
4. [Agent Skills](https://github.com/impacta-ghcp-eng-moderna/02-demo-agent-skills) — descoberta automática e carregamento progressivo de conhecimento e recursos reutilizáveis.
5. [Hooks: logs no Copilot CLI](https://github.com/impacta-ghcp-eng-moderna/02-demo-hooks-logs) — observação das invocações de hooks por meio de registros em JSONL.
6. [Hooks: logs no VS Code](https://github.com/impacta-ghcp-eng-moderna/02-demo-hooks-logs-vscode) — observação dos eventos de hooks durante o uso do Agent mode no VS Code.
7. [Hooks: prevenção](https://github.com/impacta-ghcp-eng-moderna/02-demo-hooks-prevencao) — bloqueio preventivo de alterações e exclusões em arquivos críticos.
8. [GitHub MCP Server](https://github.com/impacta-ghcp-eng-moderna/02-demo-mcp-server) — acesso mínimo, análise remota e criação supervisionada de issues.
9. [Lab 02: revisão delegada e correção supervisionada](https://github.com/impacta-ghcp-eng-moderna/02-lab) — uso de custom agents, subagents e handoffs para revisar evidências e corrigir uma lacuna delimitada.

**Apresentação:** [baixar slides do Módulo 02](./apresentacoes/02-ghcp-eng-moderna.pptx?raw=1)

## Módulo 03 — GitHub Copilot no SDLC

Uma grande demonstração, dividida em duas partes e mantida em um único repositório: primeiro, a execução de uma entrega da issue à produção; depois, a análise da entrega e a reconstrução do fluxo com controles e evidências.

1. [Demonstração: GitHub Copilot no SDLC](https://github.com/impacta-ghcp-eng-moderna/03-demo-sdlc) — acompanha o uso do Copilot ao longo do ciclo de desenvolvimento, da especificação e delegação até o pull request, a CI e a revisão.

**Apresentação:** [baixar slides do Módulo 03](./apresentacoes/03-ghcp-eng-moderna.pptx?raw=1)
