# Ementa do treinamento

## Visão geral

Treinamento: GitHub Copilot para Engenharia Moderna
Carga horária: 16 horas

Objetivo geral:
Capacitar os participantes a utilizarem o GitHub Copilot de forma estratégica no ciclo completo de desenvolvimento de software, desde a engenharia de prompts até automação de testes, refatoração, documentação e integração DevOps.

## Módulos

### 01 - Desenvolvimento de Código com GitHub Copilot
- Geração de código por descrição
- Criação de funções e classes
- Conversão de requisitos em código
- Boas práticas de geração
- APIs e microsserviços
- REST, GraphQL, middlewares e validações
- Suporte multilinguagem
- C#, Java, Python e JavaScript/TypeScript
- Clean Code com Copilot
- Legibilidade, padronização, reutilização e boas práticas

### 02 - Engenharia de Prompts e Personalização do GitHub Copilot
- Fundamentos de prompting
- Estrutura e construção de prompts eficientes
- Tipos de prompts e refinamento de respostas
- Estratégias de controle de resultados
- Prompt chaining, contexto e restrições
- Instalação e configuração do Copilot no VS Code e JetBrains
- Personalização avançada e políticas de uso
- Exercícios práticos com prompts

### 03 - GitHub Copilot no Ciclo de Vida das Aplicações
- Design e arquitetura
- Geração de diagramas e fluxos
- Estruturação inicial de projetos
- Desenvolvimento assistido
- Módulos, componentes e design patterns
- Testes e validação
- Testes unitários, mocks e cenários de integração
- Exercício integrador

### 04 - Testing, Refatoração, Documentação e DevOps
- Testes automatizados
- Casos de borda, cobertura e validação
- Refatoração com Copilot
- Otimização, duplicidade e legibilidade
- Documentação automatizada
- README, Swagger/OpenAPI e documentação viva
- Integração com Azure DevOps e GitHub
- CI/CD e pipelines YAML
- Exercício final

## Metodologia
- Aulas expositivas demonstrativas
- Hands-on labs
- Exercícios guiados
- Desenvolvimento incremental de projeto
- Estudos de caso

## Recursos
- VS Code, Visual Studio e IntelliJ/JetBrains
- Conta GitHub com GitHub Copilot habilitado
- SDKs das linguagens utilizadas

- Dia 2: Módulo 02
- Dia 3: Módulo 03
